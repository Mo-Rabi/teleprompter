## Design Context

### Users
Solo content creator filming themselves alone, using this as a personal tool to read Arabic-focused scripts while recording videos about cultural topics.

### Brand Personality
Playful & modern — fresh, energetic, connecting tradition with today. The interface should feel like a supportive tool that understands the cultural context while keeping things contemporary.

### Aesthetic Direction
Calm & focused — minimal distraction that helps the creator stay in the moment and deliver naturally. References: professional teleprompter apps (focus on layout and controls). Dark theme appropriate for filming environment.

### Design Principles
1. **Distraction-free reading**: The script text must be the hero; controls should fade away during filming
2. **Cultural authenticity**: Honor the Arabic content while maintaining modern sensibilities
3. **Filming-first UX**: Every interaction should support the actual filming workflow (setup, record, review, repeat)
4. **Playful touches**: Add personality through micro-interactions and unexpected details without compromising focus
5. **Voice-first design**: Since voice commands are a core feature, make voice feedback and status clear and reassuring
